# Documentos de salida

Este directorio contiene documentos generados por workflows del proyecto para revisión y uso del usuario, como cartas de presentación y CVs de entrega para vacantes. Cada archivo se asocia con una postulación registrada en `knowledge/postulaciones.md`.

Los documentos se generan a partir de información local del proyecto. Revisa cada archivo antes de enviarlo a un empleador. Los archivos existentes no deben sobrescribirse; las nuevas versiones se guardan con un sufijo de fecha.
